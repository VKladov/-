# Кабельный журнал и площади помещений по чертежу DWG

Скрипты читают DWG-план этажа и делают:
- **кабельный журнал** (Excel): длины линий от щитка по трассам плана плюс спуски, сводку по маркам кабеля, пояснения;
- **схему групп** (PDF, 3 листа: розетки, кондиционеры, освещение) с номерами групп на плане;
- **площади полов помещений** (Excel и PDF-план с контурами).

Скрипты настроены под конкретный чертёж: слои, цвета линий, положение щитка, контуры и названия помещений. Для другого объекта их нужно поправить (см. «Что настраивается»).

## Что нужно

- Node.js 20+. DWG читается библиотекой LibreDWG (пакет `@mlightcad/libredwg-web`), `run.sh` сам выполнит `npm install`.
- Python 3.10+ и пакеты: `pip install -r requirements.txt`.
- LibreOffice Calc — по желанию. С ним в xlsx сразу сохраняются посчитанные значения формул; Excel и так пересчитывает их при открытии.

## Запуск

```
./run.sh путь/к/плану.dwg [папка_для_результатов]
```

По умолчанию результаты складываются в `out/`:
- `Кабельный журнал.xlsx`
- `Схема групп.pdf`
- `Площади помещений.xlsx`
- `Площади помещений.pdf`

Промежуточные данные — в `build/` (`db.json` — содержимое чертежа, `groups.json` — найденные линии).

## Как считается

- **Трассы** берутся со слоёв «Электрика розетки» и «Освещение_выключатели». Вид линии определяется по цвету из легенды чертежа: розетки, розетки санузлов, кондиционеры, светильники, светильники санузлов, аварийное освещение.
- **Каждая линия** прослеживается от щитка по соединениям отрезков. Горизонтальная длина — сумма всех отрезков линии: магистраль по коридору, участки между коробками и ответвления к приборам.
- **Спуски:** 1 к щитку на каждую линию, 1 на каждую розетку, 1 на каждый выключатель, 1 от каждой коробки-светильника (квадрат с диагональю). Без спусков считаются кондиционеры и потолочные розетки.
- **Площадь помещения** — внутри контура стен (слой «Стены»), без дверных проёмов; колонны внутри помещения вычитаются.

## Что настраивается

| Файл | Что в нём |
|---|---|
| `config.py` | высоты спусков, запас к длине, марки и сечения кабеля по системам |
| `rooms.py` | контуры помещений (в каком помещении прибор) и названия помещений |
| `geom.py` | положение щитка `PANEL`, соответствие цветов линий видам |
| `analyze.py` | поправки к чертежу `VIRTUAL`: недостающий участок Р11, зазор 17 мм на АО1 |
| `areas.py` | точки внутри помещений для расчёта площадей `ROOM_SEEDS` |
| `notes.json` | тексты листа «Пояснения» (высоты спусков там записаны текстом) |
| `scheme.py`, `label_offsets.py` | положение подписей на схеме |

Номера групп (Р1…, К1…, О1…, АО1) назначаются по порядку помещений. После изменений в чертеже проверьте, что номера не сдвинулись.

## Новая версия чертежа

```
node dwg2json.mjs новый.dwg build/db_new.json
python3 compare.py build/db.json build/db_new.json   # что изменилось в проводке и стенах
./run.sh новый.dwg
```

Для проверки трасс: `python3 analyze.py` печатает все найденные линии по видам (длина, число розеток, коробок, «висящие» концы). `python3 areas.py` печатает площади помещений.

Чертежи и готовые файлы в репозиторий не добавляются (см. `.gitignore`).
